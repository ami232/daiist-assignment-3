# Source and licence

These snapshots reproduce extracts of the **Python 3.13 documentation** generated into CPython’s `pydoc_data.topics` standard-library module. Official documentation is published at https://docs.python.org/3.13/ and licensed under the Python Software Foundation License Version 2: https://docs.python.org/3.13/license.html.

Each file records the public source URL. `manifest.json` records the topics used, document version and word count. The sections are regrouped into original reference-page categories (and one library formatting category), not independently authored documents. The corpus is for educational research; check the current version of the Python documentation for operational decisions.

`incoming/pdb_reference.md` is an optional **holdout** document, excluded from the initial corpus, for a controlled before/after add-document experiment.
