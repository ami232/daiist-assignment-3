# Internal policy note: materiality threshold for past-due counting

**FICTIONAL EXAMPLE FOR A COURSE DEMONSTRATION. This is not an EBA document and not regulatory text. The figures below are invented.**

Document: Demo Bank internal model validation note DB-VAL-2026-01
Date: 2026-11-25
Scope: how the fictional Demo Bank applies the materiality threshold for counting days past due under the EBA guidelines on the application of the definition of default.

## Absolute threshold in euros

For retail exposures, Demo Bank sets the absolute component of the materiality threshold at EUR 100 (one hundred euros) per obligor. For non-retail exposures, Demo Bank sets the absolute component at EUR 500 (five hundred euros) per obligor.

## Relative component

The relative component is 1% of the total on-balance-sheet exposure to the obligor. An obligor is past due in a material way only when both components are exceeded for more than 90 consecutive days.
