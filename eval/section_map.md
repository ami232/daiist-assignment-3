# Section map (for writing and checking eval/questions.csv)

Generated from the design-B chunk metadata of the cleaned corpus, so every location below is a value
`expected_location` can take. `expected_source` is the CELEX id. Several passages: separate both columns
with `;`, in the same order (source 1 goes with location 1). Pages are physical PDF pages; HTML has none.

Both expected columns are checked against this map by `tests/test_evaluation.py`.
