# Judge rubric

## Correct

Compare the agent's answer with the reference answer. Don't use your own knowledge of UK immigration rules.

- For an answerable question, the answer is correct if it reaches the same conclusion as the reference on every part of the question: the same yes or no, and the same amounts, dates, durations and conditions.
- Each part of a multi-part question must be answered. A missing part makes the answer incorrect.
- Leaving out a condition that changes the outcome for the student is also incorrect, for example a deadline, or a requirement that a visa still be valid when they apply. Leaving out a general detail that doesn't affect the student's case is fine.
- Any wrong amount, date, duration or calculation makes the answer incorrect.
- If the reference's answer depends on a condition, a flat yes or no is incorrect.
- Extra information is fine unless it contradicts the reference.
- An answer that applies a general rule to the student's situation is correct if it reaches the reference's conclusion, even when the documents don't name that situation.
- A refusal on an answerable question is incorrect.
- For an unanswerable question, where the reference is a refusal, the answer is correct only if it refuses with the sentence "I can't find this in the documents I have." It may add one line on where to check, such as GOV.UK, a university adviser or an employer; that line doesn't have to match the reference's and doesn't count as giving information. An answer that gives information instead, even about part of the question, is incorrect.

## Supported

Compare the agent's answer with the retrieved passages shown with it. Don't use the reference answer or your own knowledge.

- The answer is supported if every factual claim in it (each rule, amount, date, condition or exception) appears in the retrieved passages or follows directly from them.
- It is unsupported if it adds anything the passages don't say, such as an extra exception, a claim about how something usually works in practice, or a fact from general knowledge, even if that fact is true.
- Applying a rule from the passages to the student's own situation is supported when it follows directly.
- A figure the answer works out from the passages is supported only if the calculation is right.
- Judge the content, not the citation labels. A claim whose content appears in the retrieved text is supported even if it cites the wrong rule number or a sub-rule inside a passage, because labels are checked separately.
- A refusal makes no factual claims, so it is supported. A one-line pointer to where to check, such as GOV.UK or a university adviser, and general advice like "check with your university" don't count as claims.
- Grade correct and supported independently: an answer can be correct but unsupported, or supported but incorrect.
