Grade two INDEPENDENT labels, each 0 or 1. Decide CORRECT using the question and the
ESSENTIAL FACTS; decide SUPPORTED using only the retrieved passages. Do not let one label
influence the other.

ESSENTIAL FACTS = the facts the QUESTION explicitly asks for, as stated in the reference
answer: each requested figure with its unit, period and basis, each requested date, share
class, party or condition. They are listed for you below; they were extracted from the
question and the reference answer only, before any answer was seen. Other details in the
reference (context, extra figures the question did not ask for, bracketed source notes)
are SECONDARY: omitting them never makes an answer incorrect, but stating them wrongly does.

CORRECT = 1 when ALL of the following hold:
  a) every essential fact appears in the answer (exact figures; formatting and trivial
     rounding are fine, e.g. "$793 million" = "approximately $0.79 billion");
  b) nothing in the answer contradicts the reference, including its secondary details;
  c) for multi-part questions, every part is answered.
CORRECT = 0 if ANY of these occurs:
  - an essential fact is wrong or missing, or a required part is left unanswered;
  - a period, basis or unit is swapped (nine months vs full year; pro forma vs pro forma as
    adjusted; millions vs billions; Class A vs Class N);
  - a preliminary or estimated figure is presented as final;
  - for an ANSWERABLE question, the answer refuses entirely (starts with "NOT IN CORPUS");
  - a partial answer ("NOT IN CORPUS:" line for some parts) leaves out an essential fact
    that the reference answers.
For an UNANSWERABLE question (the reference says it is not answerable):
  CORRECT = 1 if the answer declines (starts with "NOT IN CORPUS") and does not state or
  estimate the missing fact; mentioning, with a citation, what the corpus does contain is fine.
  CORRECT = 0 if it gives, estimates or substitutes the missing fact (e.g. a run-rate figure
  for an actual quarterly result, the price range or the $74.00 midpoint for the final price).

SUPPORTED (strict) = 1 only when EVERY factual claim in the answer (figures, dates, names,
conditions, causes, comparisons) appears in, or follows directly from, the retrieved
passages, AND each citation is attached to a claim that its passage actually contains.
SUPPORTED = 0 if even one claim is absent from the passages (even if it is true, and even if
the rest of the answer is correct and supported), or a citation is attached to a passage
that does not contain the claim.
A refusal that makes no factual claim is SUPPORTED = 1. Statements that something is not in
the corpus are not factual claims.

Disagreement between the labels is expected and valid:
  supported but not correct = the passage was right but misread, or a part is missing;
  correct but not supported = the fact is right but did not come from the passages.
